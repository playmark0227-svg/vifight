# 制作事例のスクリーンショット置き場

このフォルダに `<案件のslug>.jpg` を置くと、ポートフォリオページ
（portfolio.html）のカードとモーダルの画像が自動で差し替わります。
置かない場合は、案件のブランドカラーで作られたデザインカードが表示されます。

## 推奨サイズ

- 横1600px × 縦1000px 程度（16:10）
- JPEG、500KB以下が目安
- スマホで撮るなら、サイトのトップ画面をスクショしてそのままでもOK
